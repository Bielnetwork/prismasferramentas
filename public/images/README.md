# Imagens do PRISMA

Coloque as imagens otimizadas nesta pasta e informe os caminhos em `src/config.ts`.

Exemplo: salve `hero-prisma.webp` aqui e use `/images/hero-prisma.webp` no campo `imageConfig.hero`.

Prefira WebP ou AVIF. Mantenha os mapas em boa resolução para que continuem legíveis na ampliação.
